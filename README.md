# mbta-bus-reliability


This repository contains the code and data for my project on MBTA key bus route reliability.

The goal of the project is to explore how weather conditions and ridership affect the on-time performance of MBTA key bus routes. I clean and aggregate historical bus performance data, join it with daily weather records, and build an interactive dashboard to visualize:

- Overall reliability trends over time
- The relationship between precipitation, ridership, and on-time performance
- Differences in reliability under clear, rainy, and snowy conditions
- Route-level ridership changes by weather type
- Spatial patterns of reliability across the network

The dashboard is deployed with GitHub Pages in this repository so that users can interact with the visualizations directly in their browser.
